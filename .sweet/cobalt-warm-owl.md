New keyboard shortcuts for starting work: Cmd+Shift+N (Ctrl+Shift+N) opens a new workspace with the repository picker open, from anywhere in Geordi. Cmd+Shift+M and Cmd+Shift+E (Ctrl+Shift+M and Ctrl+Shift+E) choose the model and the effort in the message box you are typing in. Cmd+N (Ctrl+N) still opens a new workspace, but no longer opens the repository picker.
