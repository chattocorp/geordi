You can now start a workspace from another branch: pick it beside the repository when you start one. Until a workspace has a pull request, you can also change the branch its changes are compared with, from the branch named at the top of the Changes pane; and an agent that moves its work onto another branch can say so itself. In a repository with an upstream, a branch always means the upstream's copy, such as `origin/main`.
