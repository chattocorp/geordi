MCP clients outside Geordi, such as Claude Code or Codex in your terminal, can connect to Geordi with a token from Settings → Agent access. Each token is for the repositories you choose (repositories added later are not included): in those, a client can find and read workspaces, start agents and supervise them, and send follow-ups to other agents. Geordi agents can now read workspaces across all repositories too.
