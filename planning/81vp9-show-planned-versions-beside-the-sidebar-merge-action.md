title: Show planned versions beside the sidebar merge action
---
The green sidebar merge action shows one next-version pill per package with a workspace-added note and a known bump, even while the button is collapsed. Each pill displays the package name when available. Unnamed packages show only their version. Verified the pills in Chromium and the live version list against a multi-package Sweet Release worktree.
