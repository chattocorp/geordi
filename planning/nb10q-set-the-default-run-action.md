title: Set the default Run action
---
Run starts the configured job or opens the configured URL. The chevron opens the full menu. Configuration tests and Storybook interactions verify both targets and the separate menu trigger.

The MCP configuration check reports which target Run selects and whether it comes from the default setting, the first URL, or the first job.
