title: Run or edit suggested prompts inside the composer
---
The empty composer shows a suggested reply as plain text in place of the placeholder. Select the prompt to send it immediately. Press Tab in the focused text field or select the pencil to dismiss the suggestion and edit its full text. Long prompts scroll within the available space. Composer stories cover placement, scrolling, sending, editing, and Tab navigation.
