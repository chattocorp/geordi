title: Keep workspace pull requests visible across branch changes
---
Keep all known pull requests in the workspace tab, recover earlier branches, and open each review independently of the current branch.

Verified by replaying an existing three-PR workspace in an isolated forge. After a forge restart on a fresh branch, both open requests and the merged request appeared, and an earlier request opened in the detail pane.
